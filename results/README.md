# Results

One folder per release, each with:
- `servers.csv`: every candidate server, with its measures and ranks, or the reason it was excluded
- `summary.json`: the Registry snapshot time, the median, lowest and highest value of each measure, and the shares over all tools and all parameters combined
- `raw/`: the `initialize` and `tools/list` results each included server returned (from the second of its two identical readings), so anyone can recompute every number
